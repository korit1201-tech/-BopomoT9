# 安卓注音九宮格輸入法 (Android Bopomofo T9 IME)

一款專為 Android 設計的**極速、直覺、純本地離線** 12 鍵（4×3 九宮格）繁體注音輸入法。

> **致敬與資料庫來源**：  
> - 核心繁體中文詞庫全量採用開源知名 [chewing/libchewing-data](https://github.com/chewing/libchewing-data)（新酷音）官方維護之真實頻率語料庫。  
> - 12 鍵注音鍵盤手勢佈局概念參考 [Rizumu85/fcitx5-android-t9-phone](https://github.com/Rizumu85/fcitx5-android-t9-phone)。  
> - 拼寫容錯代數與聲調輪替機制參考 [SSARCandy/rime-bopomofo-t9](https://github.com/SSARCandy/rime-bopomofo-t9)。  
> 本專案採用純原生 Android Kotlin 獨立開發實現，具備獨立的前綴樹（Trie）注音斷詞與動態規劃 (DP) 全域分詞引擎。

## ✨ 核心特色與真實版面配置 (v1.4.1)

### 🔢 1. 數字 9 宮格主次視覺優化（主數字加大加粗，符號與英文縮小居中）
- **經典電話鍵盤排版**：12 鍵數字模式（NUMBER_SYM 與 9 鍵英文）按鍵採用上下分層設計，**主數字與主符號放大 1.45 倍並套用粗體（Bold）深色**，醒目不刺眼。
- **次要字元縮小 0.68 倍**：次要英文字母（如 `a b c`）與輔助符號縮小換行陳列，主次分明，解決以往字級混雜、數字不夠顯眼的問題。
- **無縫隔離切換**：切換至數字模式即時呈現精緻層次，切換回注音模式自動還原注音佈局。

### 🧭 2. 全新「四向十字羅盤」長拉拖選與動態視覺動畫 (Compass Drag-to-Select)
- **視覺指示浮層**：手指在任意 12 鍵按鍵上按住拖曳時，按鍵上方即時浮現高質感**四向十字指示盤**氣泡，清晰呈現 **上、下、左、右** 所代表的注音符號或數字/字母。
- **動態縮放高亮與彈跳動畫**：
  - 手指拖向某個方向時，目標字元**即時放大 1.35x 並亮起鮮明藍色圓圈，字體反白**，其餘方向平滑淡化。
  - 放開手指瞬間，選中字元伴隨彈性動畫消失，文字立即精準直出上屏！
  - 按鍵本體具備輕微下凹（Scale 0.96x）與回彈動態微觸反饋。
- **全字母與符號無縫拖選**：
  - **注音 9 鍵**：所有鍵位之注音符號（如 ㄅ, ㄉ, ㄚ, ㄦ 等）完全支援四向拖選直出。
  - **數字 9 鍵**：上(UP)直出數字（Key 7 支援 `s`，Key 9 支援 `z`），左/下/右直出英文字母與符號，原位短按維持點擊（數字優先）。

### 📚 3. 整合 libchewing 官方 16 萬完整詞庫 & 零韻母發音容錯
- **社群維護權威語料**：全量導入 `libchewing-data` 官方繁體中文詞庫（`tsi.csv` + `word.csv`），內含 160,000+ 筆台灣地道日常詞條與 26,000+ 筆單字，詞頻客觀標準。
- **在地口語零韻母容錯**：支援台灣常用縮讀與口語容錯（如 `ㄕㄜㄇㄜ` = `什麼`、`ㄓㄜㄇㄜ` = `這麼`），結合 ㄣ/ㄥ、ㄢ/ㄤ、ㄓ/ㄗ、ㄔ/ㄘ、ㄕ/ㄙ 混淆發音自動適配。

### 🎯 4. 階梯式候選詞排序（Tiered Ranking），藍色推薦不再混亂
- **Tier 1 (完全匹配)**：長度完全符合當前鍵位之單字或詞彙。使用者個人詞庫常選字詞依點擊次數排前，**常選字詞絕對穩居第 1 位藍色高亮**！
- **Tier 2 (一口氣長句中文預測)**：一口氣輸入 $\ge 4$ 鍵時，由 DP 全域最佳分詞合成中文句子。若當前無完全匹配詞，預測中文句**直接置頂排在第 1 位藍色高亮**，輸入框中的 Composing 預覽亦即時同步呈現中文，按空格一鍵上屏中文！
- **Tier 3 (前綴預測長詞)**：尚未打完後續鍵位之延伸長詞，永遠排在完全匹配字詞與中文句子之後，絕不可能跨層級搶占藍色候選位。

### 💡 5. libchewing 真實語料接續聯想詞，零磁碟重複讀取
- **毫秒級記憶體關聯索引**：開機載入字典時單次 Pass 構建 `nextWordMap`，選字上屏後以 $O(1)$ 速度從 libchewing 真實頻率推薦最自然接續詞。
- **防抖定時合併儲存**：`UserDictionaryManager` 採用 2.5 秒防抖寫檔機制，打字與選字完全在記憶體中極速運算，徹底杜絕磁碟 IO 阻塞與 Trie 反覆重建。

### 📳 6. 設定頁面專屬按鍵震動開關與即時強度試聽滑桿
- **獨立觸覺控制**：不依賴系統全局易失效的 `HAPTIC_FEEDBACK_ENABLED`，輸入法提供獨立的開關與強度設定。
- **滑動即試聽**：
  - **震動開關 (Switch)**：一鍵啟用/關閉按鍵震動。
  - **震動強度滑桿 (SeekBar，5 ms ~ 100 ms)**：可自訂震動時間與振幅，拉動滑桿時手機即時震動試聽，調配最舒適手感。
  - 鍵盤「123」鍵支援長按直達此設定頁面。

### ⌨️ 7. 人體工學版面配置
- **英文 26 鍵 (QWERTY)**：移除多餘按鈕，空白鍵回歸純輸入空格；頂部整合常用符號專屬列（`+ - * / = ( ) @ _ &`），字母鍵支援長按直出數字與標點。
- **換行鍵與清空鍵最佳化**：中文注音模式下，右側 `@` 位置改為換行鍵 `↵`；數字模式下，清空鍵改為換行鍵。
- **輸入模式快速切換**：
  - 中文切換英文時以 26 鍵 QWERTY 優先顯示；
  - 數字模式整合 9 鍵英文，數字優先、連按出英文。
- **Google ML Kit 高精度手寫**：空白鍵滑動自由切換「繁」→「簡」→「手」，端側 AI 離線推論。
- **鍵盤高度自由拉伸（Drag-to-Resize）**：拖動把手自由縮放高度（180dp ~ 380dp），自動記憶偏好。
- 🚀 **應用內線上檢查更新（方案 A 一鍵下載覆蓋安裝）**：
  - 設定頁面提供「🔍 檢查 GitHub 新版本」按鈕，即時比對遠端 Releases。
  - 發現新版彈出更新對話框與 Release Notes，點擊「立即下載並更新」後由系統 `DownloadManager` 背景下載 APK，並透過 `FileProvider` 自動喚起系統安裝器完成無縫覆蓋更新。

## 🛠️ 開發與建置

### 環境需求
- Android Studio Iguana / Jellyfish 或更新版本
- Android SDK 34 (minSdk 24)
- JDK 17 / Java 1.8+

### 本地編譯
```powershell
# Windows PowerShell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
./gradlew assembleRelease
```
編譯產物位於 `app/build/outputs/apk/release/app-release.apk`。
