# 安卓注音九宮格輸入法 (Android Bopomofo T9 IME)

一款專為 Android 設計的**極速、直覺、純本地離線** 12 鍵（4×3 九宮格）繁體注音輸入法。

> **致敬與語料來源**：  
> - 核心繁體中文詞庫全量採用開源知名 [chewing/libchewing-data](https://github.com/chewing/libchewing-data)（新酷音）官方維護之真實頻率語料庫。  
> - 12 鍵注音鍵盤佈局與手勢概念參考 [Rizumu85/fcitx5-android-t9-phone](https://github.com/Rizumu85/fcitx5-android-t9-phone)。  
> 本專案採用純原生 Android Kotlin 開發，具備獨立的前綴樹（Trie）注音斷詞與動態規劃 (DP) 全域分詞引擎。

---

## ✨ 核心特色

### ⌨️ 1. 九宮格（4×3）極速注音輸入
- **經典 12 鍵佈局**：大按鍵間距，大幅減少誤觸，單手盲打舒適自然。
- **權威 16 萬官方詞庫**：內建新酷音（libchewing）官方 160,000+ 筆繁體生活常用詞條與 26,000+ 筆單字，選詞地道精準。
- **一口氣長句預測**：輸入連續按鍵時，由全域最佳分詞演算法自動組合最佳中文長句，按空白鍵一鍵上屏。
- **在地口語容錯**：
  - 支援零韻母口語縮讀（如 `ㄕㄜㄇㄜ` $\rightarrow$ `什麼`、`ㄓㄜㄇㄜ` $\rightarrow$ `這麼`）。
  - 自動適配捲舌與平舌（ㄓ/ㄗ、ㄔ/ㄘ、ㄕ/ㄙ）、前後鼻音（ㄣ/ㄥ、ㄢ/ㄤ）模糊比對。

### 🧭 2. 四向十字羅盤拖選直出 (Compass Drag-to-Select)
- **四向直覺操作**：按住任意 12 鍵向 **上、下、左、右** 滑動，即可精準直出各方位符號或字母。
- **動態羅盤視覺動畫**：手指滑動時即時彈出十字指示浮盤，選取目標放大高亮，放手瞬間彈性直出上屏。
- **空白鍵滑動切換**：空白鍵常駐提示 `‹ 簡體 · 手寫 ›`，向左向右滑動即可在繁體、簡體與手寫模式間迅速切換。

### 🔢 3. 電話鍵盤九宮格與多模式輸入
- **經典數字九宮格**：12 鍵數字模式採用主數字加大加粗深色排版，次要字母與符號優雅縮小居中，主次分明。
- **英文 26 鍵 QWERTY**：全鍵盤英文佈局，頂部整合常用符號列，支援長按字母直出數字與標點。
- **端側 AI 手寫輸入**：整合 Google ML Kit 離線手寫辨識，支援繁簡中文字筆畫辨識與全畫布手寫，底部具備退格刪除鍵。

### 🎯 4. 階梯式候選詞排序與智慧接續聯想
- **嚴謹階梯式排序**：
  - **Tier 1**：完全匹配字詞（常選詞置頂第一位藍色高亮）。
  - **Tier 2**：一口氣輸入時的最佳中文句子預測。
  - **Tier 3**：後續延伸詞聯想。
- **毫秒級接續聯想詞**：選字上屏後，依據真實語料頻率推薦最自然接續詞，打字如行雲流水。

### 🧠 5. 本地個人化學習與詞庫備份
- **智慧詞頻記憶**：全自動學習使用者的選詞偏好，越常打的詞權重越高，優先浮上第 1 位。
- **詞庫匯出與匯入**：支援 Storage Access Framework 匯出/匯入標準 TSV 文字檔（`bopomofo_user_dict.txt`），換機備份無憂。
- **100% 離線純本地儲存**：學習紀錄僅儲存於裝置端，零隱私洩露風險。

### 📳 6. 極致體驗與外觀自訂
- **專屬按鍵觸覺震動**：獨立開關與震動強度調整滑桿（5 ms ~ 100 ms），滑動即時震動試聽，調配最舒適手感。
- **鍵盤高度自由拉伸**：長拉鍵盤手柄自由縮放高度（180dp ~ 380dp），自動記憶偏好設定。
- **直覺設定入口**：中英切換鍵「中/EN ⚙」支援長按直達設定頁面，單鍵搞定中英切換與面板設定。

### ⚡ 7. 輕量高效與安全防護
- **極速秒開啟動**：詞庫採用背景非同步加載，切換鍵盤立即跳出，零卡頓延遲。
- **零延遲觸控派發**：手指離開螢幕瞬間立即送出按鍵，高速盲打永不漏字或倒序。
- **超低記憶體佔用**：極致優化的前綴樹資料結構，常駐運作輕盈省電。
- **應用內線上一鍵更新**：設定頁面內建 GitHub Release 檢查，一鍵在線下載並自動安裝最新版本。

## 🛠️ 開發與建置

### 環境需求
- Android Studio Iguana / Jellyfish 或更新版本
- Android SDK 34 (minSdk 24)
- JDK 17 / Java 1.8+

### 本地編譯
```powershell
# Windows PowerShell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
./gradlew assembleRelease
```
編譯產物位於 `app/build/outputs/apk/release/app-release.apk`。
