# All's good注音九宮格輸入法 (All's Good Bopomofo IME)

一款專為 Android 設計的**極速、直覺、純本地離線**繁體注音輸入法。完整支援 **12 鍵（4×3 九宮格）** 與 **41 鍵標準大千注音全鍵盤**，並具備強大的**聲母簡拼（偷懶輸入）**與智慧預測能力。

> **致敬與語料來源**：  
> - 核心繁體中文詞庫全量採用開源知名 [chewing/libchewing-data](https://github.com/chewing/libchewing-data)（新酷音）官方維護之真實頻率語料庫。  
> - 12 鍵注音鍵盤佈局與手勢概念參考 [Rizumu85/fcitx5-android-t9-phone](https://github.com/Rizumu85/fcitx5-android-t9-phone)。  
> 本專案採用純原生 Android Kotlin 開發，具備獨立的前綴樹（Trie）注音斷詞、動態規劃 (DP) 全域分詞引擎，以及專為全鍵盤設計的教育部標準音節簡打預測引擎。

---

## ✨ 核心特色

### ⌨️ 1. 雙注音模式：9 鍵九宮格 ＋ 41 鍵大千全鍵盤
- **經典 9 鍵九宮格（4×3）**：
  - 大按鍵間距，大幅減少誤觸，支援單手盲打。
  - 一口氣長句預測：連續點按時由全域最佳分詞演算法自動組合中文長句，空白鍵一鍵上屏。
  - 在地口語容錯：支援零韻母縮讀（`ㄕㄜㄇㄜ` $\rightarrow$ `什麼`）、平捲舌（ㄓ/ㄗ、ㄔ/ㄘ、ㄕ/ㄙ）、前後鼻音（ㄣ/ㄥ、ㄢ/ㄤ）模糊比對。
- **全新 41 鍵標準大千注音全鍵盤**：
  - 標準大千注音排版（Row 1~4），第 1 排長按可直出數字 `1 ~ 0`。
  - **右上角專用退格鍵（`⌫`）**：符合電腦實體大千注音鍵盤習慣，長按支援連續退格。
  - **右下角專用換行鍵（`↵`）**：組字中一鍵確認上屏，無組字時正常換行。
  - **左下角「清空」鍵**：點擊一鍵清除所有未上屏注音符號。

### 🚀 2. 專屬聲母簡拼與混合偷懶輸入（全鍵盤專屬預測）
- **100% 精準音節切分**：基於教育部標準 429 個合法音節回溯切分，全量 13.3 萬筆詞庫 100% 精確抽取各字首碼建立索引。
- **純首碼簡拼（偷懶輸入）**：
  - 輸入 `ㄐㄊ` $\rightarrow$ 秒出 **「今天」**、家庭、交通、具體...
  - 輸入 `ㄋㄏ` $\rightarrow$ 秒出 **「你好」**、女孩、南韓...
  - 輸入 `ㄅㄓㄉ` $\rightarrow$ 秒出 **「不知道」**、不正當...
  - 輸入 `ㄨㄇ` $\rightarrow$ 秒出 **「我們」**、完美、文明...
  - 輸入 `ㄊㄨ` $\rightarrow$ 秒出 **「台灣」**、臺灣、天文、圖文...
- **混合簡打（首字全拼＋後字簡拼）**：
  - 輸入 `ㄐㄧㄣㄊ` $\rightarrow$ 智能切分前綴音節 `ㄐㄧㄣ` 與後續首碼 `ㄊ`，秒速命中 **「今天」**！
- **全拼與單字聯想**：全拼前綴與單字同音字即時呈現，徹底與 9 鍵隔離，精準不干擾。

### 🔀 3. 空白鍵三態滑動切換 ＆ 萬用樞紐鍵
- **空白鍵三態滑動切換**：
  - 左右滑動空白鍵即可在 **「中文 ↔ 英文(26鍵) ↔ 手寫」** 三大輸入模式間迅速循環切換，按鍵常駐方向提示標籤。
- **右下角萬用樞紐鍵（Lang Toggle）**：
  - **中文模式下**：單擊即時切換 **「9鍵 ↔ 41鍵全鍵盤」**（文字顯示 `9鍵·繁` / `全鍵·繁`）；長按切換 **「繁體 ↔ 簡體」**。
  - **英文模式下（QWERTY）**：專屬 **「' 常用縮寫」** 鍵，單擊直接上屏單引號 `'`（極速輸入 `I'm`, `don't`, `it's` 等），長按彈出常用英文縮寫與網址後綴選單（.com, .tw, @gmail.com, e.g., etc. 等）並直達常用短語庫。Shift 鍵支援直覺三態切換（小寫 ⇧ / 單次大寫 ⬆ / 大寫鎖定 ⇪）。

### 🧭 4. 四向十字羅盤拖選直出 (Compass Drag-to-Select)
- **四向直覺操作**：按住 9 鍵向 **上、下、左、右** 滑動，即可直出各方位注音符號或字母。
- **動態羅盤視覺動畫**：手指滑動時即時彈出十字指示浮盤，選取目標放大高亮，放手瞬間彈性直出上屏。

### 🔢 5. 數字九宮格與專用括號滑動鍵 `( )`
- **經典數字九宮格**：12 鍵數字模式採用主數字加大加粗深色排版，次要字母與符號優雅縮小居中，主次分明。
- **專用括號滑動鍵 `( )`**：
  - **向左滑動**：輸出左括號 `(`
  - **向右滑動**：輸出右括號 `)`
  - **單擊點按**：輸出成對括號 `()`，並自動將游標置中，立即開始打字。

### 📋 6. 展開式多列候選字格柵（Grid Expansion）
- **一鍵展開大面積挑字盤**：候選列最右側常駐 `▼` 展開按鈕，點擊彈出 3~4 列大面積格柵，大字距直覺挑字，垂直平滑捲動，告別單行左右橫捲。
- **點擊自動選字上屏並收合**：點選任意字詞立即上屏並自動收合格柵，恢復原打字鍵盤；亦可點擊頂部 `▲` 手動收合。

### 🧠 7. Bigram 上下文語境感知與個人動態詞對記憶
- **上下文關聯動態加權**：依據最近確認上屏的詞彙（`contextWord`），對符合生活語境的候選詞給予加權（如「去醫院」後輸入「ㄔ」，自動將「藥」優先於「飯」）。
- **個人詞對自動學習**：每次確認上屏自動學習相鄰詞對搭配，打字越久越聰明。
- **個人詞庫絕對首選（50,000,000 權重置頂）**：選定確認的字詞立即動態注入 Trie 字典，保證後續輸入時穩居第 1 位。
- **文字區底線選詞替換**：在目標 App 文字框長按反白正在組字的底線字，候選列即時切換為該字的同音/同鍵組合展開替換。

### 📑 8. 整合式符號、剪貼簿、Emoji 與生產力抽屜（`✛`）
- 候選列最左側常駐 `✛` 按鈕，點擊展開全功能橫捲分頁抽屜：
  - **全形 / 半形 / 數學符號**：常用標點符號與運算符。
  - **方向鍵盤（D-Pad）**：方向鍵（▲▼◀▶）、Home、End、全選、複製、貼上與 **單手模式一鍵切換鍵**。
  - **📋 鍵盤剪貼簿歷史**：自動保存最近 20 筆複製文字，點擊一鍵直接貼上，密碼框自動隱私防護。
  - **😀 Emoji 表情符號**：整合於符號抽屜中，點選即上屏，不干擾注音候選列。
  - **顏文字庫**：精選 25 組台灣網路常用顏文字（如 `( ´ ▽ ` )ﾉ`、`( ›◡‹ )`、`(*^▽^*)`、`ಠ_ಠ`）。
  - **🔗 常用短語 / 巨集（Snippets）**：縮寫快速展開地址、電話、感謝詞等長文短語。

### 🎨 9. 多套主題系統與單手模式
- **8 套高反差鮮活主題風格**：
  - `跟隨系統`（自動跟隨 Android 系統深色/淺色模式）
  - `簡潔純白`、`黑曜極致`、`晴空亮藍`、`櫻花粉黛`、`日落暖橙`、`薄荷青翠`、`復古羊皮`
- **單手模式佈局**：支援 75% 寬度縮排，可靠左或靠右錨定，徹底解放大螢幕手腕負擔。
- **多級細緻觸覺震動**：細分普通按鍵（輕震）、確認上屏（雙脈衝）、退格刪除（清脆震）、長按連續退格（8ms微脈衝）。
- **應用內線上一鍵更新**：設定頁面內建版本更新檢查，直連本地高速下載安裝。

## 🛠️ 開發與建置

### 環境需求
- Android Studio Iguana / Jellyfish 或更新版本
- Android SDK 34 (minSdk 24)
- JDK 17 / Java 1.8+

### 本地編譯
```bash
./gradlew assembleRelease
```
編譯產物位於 `app/build/outputs/apk/release/app-release.apk`。
